本模块由三个职责清晰的 Go 文件组成，均属于 `service` 包，依赖 `model` 层持久化用户会话与审计数据，并通过 `common` 提供随机数、HMAC、配置常量。
- `auth_token.go`：基于 `golang-jwt/jwt/v5` 的 HS256 签名 JWT 实现，定义 `AuthIdentity` 结构体与 `authClaims`，分别负责 Access Token（15 分钟）与安全证明令牌（5 分钟）的签发与解析，通过 `authSigningKey(purpose)` 按用途派生不同密钥。
- `auth_session.go`：围绕 `UserSession` 模型实现登录会话的创建、验证、刷新、撤销与列表查询；Refresh Token 采用 `sid.secret` 明文拼接 + HMAC 哈希存储，支持滚动更新与防重放窗口（30 秒）；提供 `AuthBundle` 聚合返回 AccessToken 与 Session 视图。
- `auth_cleanup.go`：仅主节点执行的定时任务（每小时），清理过期/已撤销的用户会话与一次性认证流程，并统计每小时会话发放量以触发告警阈值。
依赖方向单向向下：service → model/common，不反向依赖上层路由或控制器。
