- 可选字段统一使用 `json.RawMessage` 或指针类型（`*bool`、`*uint`、`*float64`）并配合 `omitempty` 标签，以支持上游厂商参数透传与零值区分。
- 所有请求结构体均需实现 `Request` 接口（`GetTokenCountMeta`、`IsStream`、`SetModelName`），并通过 `BaseRequest` 提供默认空实现以降低样板代码。
- 媒体内容（图片、音频、文件、视频）通过 `MediaContent` 联合结构 + `ParseContent` 方法统一解析，支持字符串与数组两种输入格式。
- 错误响应统一使用 `GeneralErrorResponse` 结构，并提供 `TryToOpenAIError()` 和 `ToMessage()` 方法兼容多种上游错误格式。
- 自定义 JSON 类型（`StringValue`、`IntValue`、`BoolValue`）通过实现 `UnmarshalJSON`/`MarshalJSON` 同时支持字符串与原始类型的双向转换。
- 每个 DTO 文件通常配套同名 `*_test.go` 测试文件，针对边界条件与零值行为进行验证。
