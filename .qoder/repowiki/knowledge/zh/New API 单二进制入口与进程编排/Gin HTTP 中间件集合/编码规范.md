- 每个中间件以返回 `func(c *gin.Context)` 的函数形式暴露，内部通过 `c.Next()` 调用后续处理器，并在异常分支中调用 `c.Abort()` 终止链式处理。
- 错误响应统一通过 `utils.go` 中的 `abortWithOpenAiMessage`/`abortWithMidjourneyMessage` 封装，返回包含 `error.message`、`type`、`code` 的标准结构。
- 上下文数据通过 `c.Set(key, value)` 传递，跨中间件共享时使用 `common.SetContextKey` / `common.GetContextKey` 访问 typed context key。
- 国际化消息统一通过 `i18n.T(c, i18n.MsgXxx, ...)` 获取，禁止硬编码中文文本。
- 限流类中间件遵循「Redis 优先，不可用时回退内存」模式，通过 `common.RedisEnabled` 开关动态选择实现。
- 鉴权相关中间件将用户信息写入 `c.Set("id"|"username"|"role"|...)` 并调用 `user.WriteContext(c)` 同步上下文，便于后续 handler 直接读取。
