模块由三个部分组成：
- `i18n.go`：核心运行时逻辑。使用 `//go:embed locales/*.yaml` 将三种语言的 YAML 资源编译进二进制；通过 `i18n.NewBundle` + `RegisterUnmarshalFunc("yaml", ...)` 注册 YAML 解析器，并在 `Init()` 中单例初始化 bundle 与预创建的 Localizer 缓存（`localizers map[string]*i18n.Localizer`），通过 `sync.Once` + `sync.RWMutex` 保证并发安全。
- `keys.go`：集中定义所有翻译键常量（如 `MsgInvalidParams` → `"common.invalid_params"`），供业务层统一引用，避免硬编码字符串。
- `locales/`：按语言分文件的 YAML 键值对（`en.yaml`、`zh-CN.yaml`、`zh-TW.yaml`），键名采用 `领域.子域.具体项` 的命名空间约定。

依赖方向：本模块依赖 `common`、`constant`、`dto` 三个上层包以注入 `TranslateMessage` 回调并读取上下文中的用户设置；同时通过可插拔的 `userLangLoaderFunc`（由 model 包设置）反向解耦用户语言加载，避免循环依赖。语言解析遵循四级优先级：已加载的用户设置 → 懒加载用户语言 → 中间件设置的 ContextKeyLanguage → Accept-Language 头 → 默认英文。
