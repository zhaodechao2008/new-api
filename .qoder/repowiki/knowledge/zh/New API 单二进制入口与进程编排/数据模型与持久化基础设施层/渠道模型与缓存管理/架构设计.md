本模块围绕 `Channel` 结构体及其衍生类型组织，分为三层：
- 数据层（channel.go）：定义 `Channel`、`ChannelInfo`、`ChannelSortOptions` 等 GORM 模型，提供 CRUD、批量插入/删除、按 tag/group/model 搜索、状态更新、配额统计等方法；通过 `driver.Valuer`/`sql.Scanner` 实现 `ChannelInfo` JSON 字段序列化。
- 缓存层（channel_cache.go）：在进程内维护 `group2model2channels`（组→模型→渠道ID列表）、`channelsIDM`（ID→Channel）和 `channel2advancedCustomConfig` 三个全局 map，通过 `channelSyncLock` 读写锁保护；`InitChannelCache` 从 DB 全量初始化并按 priority 排序，`SyncChannelCache` 定时刷新；`GetRandomSatisfiedChannel` 基于优先级分层 + 权重随机算法选择可用渠道，并支持 Advanced Custom 类型的请求路径过滤。
- 能力匹配层（channel_satisfy.go）：提供 `IsChannelEnabledForGroupModel` / `IsChannelEnabledForAnyGroupModel` 快速判断某 channel 是否满足 group+model 的能力要求，优先走内存缓存，否则回退到 Ability 表查询。
依赖方向单向：channel_satisfy.go → channel_cache.go → channel.go；所有文件共享 `common`、`constant`、`dto`、`logger` 等包，不反向依赖上层。
