- 对 Channel 的可选字段统一使用指针类型（如 *string、*int64、*uint），并通过 GetXxx() 方法提供默认值访问器。
- 数据库查询统一通过 GORM 的 `DB.Model(&Channel{})` 构造，并在非 selectAll 场景下使用 `.Omit("key")` 避免泄露密钥。
- 内存缓存读写均通过 `channelSyncLock` 的 RLock/Lock 保护，读操作使用 RLock，写操作先加锁再调用 `InvalidatePricingCache()` 且注意锁顺序避免 AB-BA 死锁。
- 多 Key 模式的状态变更通过 `GetChannelPollingLock(channelId)` 获取 per-channel 互斥锁，保证 `MultiKeyStatusList` 等 map 的并发安全。
- 设置字段（Setting、OtherSettings、OtherInfo）统一通过 `common.Unmarshal`/`common.Marshal` 进行 JSON 序列化，失败时记录日志并清理或返回错误。
