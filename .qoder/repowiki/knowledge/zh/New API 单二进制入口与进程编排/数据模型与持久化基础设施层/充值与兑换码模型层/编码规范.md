- 所有涉及状态变更的写操作都通过 DB.Transaction + lockForUpdate(tx).Where(...).First(...) 加行级锁，再在事务内原子更新订单与用户额度，确保并发安全。
- 跨数据库方言的列名引用通过 common.UsingMainDatabase(common.DatabaseTypePostgreSQL) 判断后选择反引号或双引号包裹（如 `trade_no` / "trade_no"）。
- 分页查询统一采用 Begin() → Count() → Find() → Commit() 三段式模式，并在 defer 中 recover 后 Rollback() 保证异常回滚。
- 支付渠道通过常量区分：PaymentMethod* 与 PaymentProvider* 两组常量分别表示支付方式与上游提供商，回调函数内部校验 topUp.PaymentProvider 与预期值是否一致，不一致返回 ErrPaymentMethodMismatch。
- 对外错误通过 errors.New 定义命名错误变量（如 ErrTopUpNotFound、ErrTopUpStatusInvalid、ErrPaymentMethodMismatch），并在业务函数中返回而非直接 panic。
- 充值成功后统一调用 RecordTopupLog 或 RecordLog 记录日志，且日志记录放在事务外执行以避免阻塞事务。
