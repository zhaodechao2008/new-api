- 每个上游 channel 目录必须实现 Adaptor 接口（Init/ConvertXxxRequest/DoRequest/DoResponse 等），并通过 GetAdaptor 的 switch 分支暴露。
- RelayInfo 通过 GenRelayInfo* 工厂函数按协议类型构造，禁止直接 new 赋值，确保 ChannelMeta、StreamStatus、Billing 等字段正确初始化。
- 计费逻辑统一走 RelayInfo.BillingSettler 的生命周期（预扣 EstimateBilling → 提交 AdjustBillingOnSubmit → 完成 AdjustBillingOnComplete），适配器不得自行扣费。
- 请求体裁剪使用 RemoveDisabledFields / RemoveGeminiDisabledFields 基于 ChannelOtherSettings 配置过滤敏感字段，禁止在适配器内硬编码白名单。
- TaskAdaptor 必须实现 ValidateRequestAndSetAction + BuildRequestBody + DoResponse + FetchTask + ParseTaskResult 五件套，以支持统一的异步任务提交流程。
