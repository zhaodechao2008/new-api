模块以 relay_adaptor.go 中的 GetAdaptor / GetTaskAdaptor 为中央调度入口，根据 constant.APIType 或 TaskPlatform 返回对应 channel/* 下的具体 Adaptor 实现；所有适配器均实现 channel/adapter.go 定义的 Adaptor / TaskAdaptor 接口，从而屏蔽各上游差异。
- 请求生命周期：handler（chat/image/audio/embedding/rerank/responses/ws）→ GenRelayInfo* 构造 RelayInfo → GetAdaptor 获取 Adaptor → ConvertXxxRequest 转换请求 → DoRequest/DoResponse 发起调用 → common/billing 完成预扣与结算。
- RelayInfo（relay/common/relay_info.go）是贯穿全链路的上下文载体，承载用户/令牌信息、ChannelMeta、计费会话 BillingSettler、流状态 StreamStatus、请求转换链 RequestConversionChain 等，由 genBaseRelayInfo 统一初始化。
- channel/task/* 子目录复用相同 TaskAdaptor 模式处理异步任务（视频/音乐生成），通过 FetchTask/ParseTaskResult 配合 polling 循环完成结果拉取与配额调整。
- 顶层 handler 文件按协议拆分（chat_completions_via_responses.go、claude_handler.go、gemini_handler.go、image_handler.go、audio_handler.go、responses_handler.go、websocket.go），但都依赖同一套 RelayInfo + Adaptor 契约，保证新增渠道只需实现一个 Adaptor 即可接入。
