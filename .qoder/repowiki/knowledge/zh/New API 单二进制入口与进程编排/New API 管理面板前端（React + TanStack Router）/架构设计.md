应用以 `src/main.tsx` 为入口，通过 Rsbuild + Rspack 构建，使用 TanStack Router 文件路由（`src/routes/` 下按 `(auth)`、`(errors)`、`_authenticated` 等分组组织），根路由 `__root.tsx` 统一处理会话引导、setup 状态检查与全局错误页。

- 分层结构：`features/` 按业务域划分（auth、channels、models、playground、dashboard、system-settings 等），每个 feature 内部遵循 `components/`、`hooks/`、`lib/`、`api.ts`、`types.ts` 的固定布局；`components/ui/` 为 shadcn 基础组件，`components/layout/` 提供页面级布局；`context/` 暴露 Theme、Font、Direction 等全局上下文；`stores/` 使用 Zustand 管理 auth、notification、system-config 等跨组件状态。
- 数据层：所有 HTTP 请求通过 `lib/http-client.ts`（Axios 封装）发起，`lib/api.ts` 作为公共 API 聚合出口，各 feature 再按需导出自身 api；TanStack Query 在 `main.tsx` 中配置重试、错误处理与 500 自动跳转。
- 样式与主题：Tailwind CSS 4 + CSS Variables，主题切换由 `next-themes` 驱动，VChart 图表主题通过 html 的 light/dark class 同步。
- 国际化：i18next + react-i18next，多语言 JSON 存放在 `i18n/locales/`，通过 `scripts/sync-i18n.mjs` 同步键值。
- 构建产物输出到 `dist/`，生产模式启用代码分割（vendor-react、vendor-ui-primitives、vendor-tanstack 独立 chunk），开发模式通过 Rsbuild proxy 转发 `/api`、`/mj`、`/pg` 到后端。
