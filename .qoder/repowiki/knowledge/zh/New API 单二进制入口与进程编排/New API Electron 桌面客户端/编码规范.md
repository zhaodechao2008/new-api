- 主进程与渲染进程通信严格通过 `contextBridge.exposeInMainWorld` 暴露白名单 API，禁止在渲染进程直接访问 Node.js 模块。
- 进程间依赖通过环境变量传递（如 `PORT`、`SQLITE_PATH`、`ELECTRON_DATA_DIR`），而非命令行参数或配置文件。
- 错误诊断遵循「收集 stderr → 正则匹配已知错误类型 → 弹出带解决方案的对话框 → 可选保存日志」的统一流程。
- 平台差异通过 `process.platform` 分支处理（macOS 用模板图标、Windows 用彩色图标、路径分隔符等），避免硬编码路径。
- 开发/生产模式通过 `NODE_ENV === 'development'` 判断，开发时跳过后端启动并直连前端开发服务器，生产时从 `process.resourcesPath/bin/` 启动嵌入的二进制。
