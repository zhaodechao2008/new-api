模块采用典型的 Electron 主进程 + preload 桥接架构：`main.js` 作为入口，负责生命周期管理（`app.whenReady`）、通过 `child_process.spawn` 启动 Go 二进制 `new-api`（开发模式从仓库根读取，生产模式从 `process.resourcesPath/bin/` 读取）、轮询端口 3000 确认后端就绪后创建 `BrowserWindow` 并加载 `http://127.0.0.1:<port>`；`preload.js` 仅通过 `contextBridge.exposeInMainWorld` 暴露只读的环境信息（`isElectron`、`version`、`platform`、`dataDir`），保持 `nodeIntegration: false` 与 `contextIsolation: true` 的安全隔离。托盘功能由 `createTray()` 实现，macOS 使用模板图标自动适配主题，Windows 使用彩色图标。构建配置集中在 `package.json` 的 `build` 字段中，借助 `electron-builder` 按平台生成 `.dmg/.zip`（macOS）、`.exe`（Windows NSIS）、`.AppImage/.deb`（Linux），并通过 `extraResources` 将预编译的 Go 二进制和许可证文件打入包内。`build.sh` 是统一的快速构建脚本，依次执行前端 `bun build`、Go 交叉编译、`npm run build:*`。错误处理链路完整：捕获 stderr → 分析常见错误类型（端口占用、数据库锁定、权限、网络、配置、内存不足、文件缺失）→ 弹出带解决方案的对话框 → 可选保存并打开日志文件。
