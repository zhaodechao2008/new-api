本模块是 new-api 的 Web 请求入口，所有文件均为 `package controller`，每个文件按业务域划分（如 user.go、channel.go、token.go、billing.go、subscription_*.go、topup_*.go 等），每个函数以 `func Xxx(c *gin.Context)` 形式暴露一个路由处理器。
- 请求处理分层：控制器仅负责参数绑定、鉴权上下文读取、调用 service/model/relay 层，不直接操作数据库；CRUD 逻辑委托给 `model.*` 包，计费与业务编排委托给 `service.*` 包。
- 统一响应格式：通过 `common.ApiSuccess` / `common.ApiError` / `common.ApiErrorI18n` 返回 `{success, data, message}` 结构，错误码集中在 `types.NewAPIError`。
- Relay 转发核心在 `relay.go`：根据 `relayFormat` 和 `RelayMode` 分派到 Text/Image/Audio/Embedding/Responses/Gemini 等 Helper，内部通过 `relay.GetAdaptor(apiType)` 动态选择下游通道适配器。
- 权限控制：鉴权由 middleware 完成，控制器内通过 `service/authz` 做细粒度授权（如 channel_authz.go 中的敏感字段 fail-closed 检查）。
- 初始化与常量：`model.go` 的 `init()` 会扫描所有 channel adaptor 构建 OpenAI 兼容的模型列表缓存；`setup.go` 提供系统首次安装流程。
- 依赖方向单向向外：controller → model/service/relay/common/constant/dto/i18n/middleware，不反向依赖上层。
