- 每个 HTTP 处理器函数签名固定为 `func Xxx(c *gin.Context)`，通过 `c.GetInt("id")`、`c.GetString(...)` 从上下文读取已解析的用户与 token 信息。
- 统一使用 `common.ApiSuccess(c, gin.H{...})` 成功返回，`common.ApiError` / `common.ApiErrorI18n` 返回错误，禁止直接 `c.JSON` 构造响应体。
- JSON 请求体通过 `c.ShouldBindJSON(&struct{})` 绑定，校验失败后直接调用 `common.ApiErrorI18n` 返回 i18n 错误消息。
- 分页查询统一通过 `common.GetPageQuery(c)` 获取 pageInfo，再配合 `pageInfo.GetStartIdx()` / `GetPageSize()` 构造 GORM 查询。
- 对外部依赖的错误统一包装为 `types.NewAPIError`，并通过 `helper.WssError` / `ToOpenAIError()` 转换为对应协议格式返回。
- 敏感字段变更采用 fail-closed 策略：通过白名单 map（如 `channelSensitiveFields`、`channelNonSensitiveFields`）显式声明可编辑字段，未知字段默认视为敏感。
