本模块为纯数据契约层（无业务逻辑），按上游厂商与功能域拆分为多个文件：
- 通用接口与基类：`request_common.go` 定义 `Request` 接口（`GetTokenCountMeta`、`IsStream`、`SetModelName`）及 `BaseRequest` 默认实现，所有请求结构体均通过实现该接口被统一处理。
- OpenAI 兼容协议：`openai_request.go`、`openai_response.go`、`openai_image.go`、`openai_video.go`、`openai_compaction.go`、`openai_responses_compaction_request.go` 覆盖 chat/completions、responses、图像、视频、压缩等场景。
- 其他厂商适配：`gemini.go`、`claude.go`、`suno.go`、`midjourney.go` 分别对应各厂商特有请求/响应结构。
- 辅助领域：`error.go` 提供 `GeneralErrorResponse` 统一错误解析；`values.go` 提供 `StringValue`/`IntValue`/`BoolValue` 自定义 JSON 类型；`task.go` 定义异步任务通用结构；`billing_usage.go`、`pricing.go`、`channel_settings.go`、`user_settings.go`、`notify.go`、`ratio_sync.go`、`realtime.go`、`rerank.go`、`embedding.go`、`audio.go`、`video.go`、`playground.go`、`sensitive.go` 等按功能域拆分。
依赖方向单向向外：仅依赖 `github.com/QuantumNous/new-api/types`、`common`、`gin-gonic/gin`、`samber/lo`，不反向依赖上层业务包。
