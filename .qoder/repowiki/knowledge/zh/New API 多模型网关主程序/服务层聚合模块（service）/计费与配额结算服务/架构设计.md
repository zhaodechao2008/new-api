本模块以 `BillingSession`（billing_session.go）为核心会话对象，封装单次请求的预扣费→结算→退款全生命周期，并通过 `FundingSource` 抽象支持钱包与订阅两种资金来源；`PreConsumeBilling` / `SettleBilling`（billing.go）作为统一入口，根据 `relayInfo.BillingPreference` 在 wallet_first / subscription_first / wallet_only / subscription_only 之间回退。

内部按职责分层：
- 会话与资金层：`billing_session.go` 定义 `BillingSession`、`WalletFunding`、`SubscriptionFunding`，通过互斥锁保证 Settle/Refund/Reserve 的幂等与原子回滚。
- 配额计算层：`quota.go` 提供通用音频/文本配额计算、WSS 实时流配额、PostConsumeQuota 统一落库；`text_quota.go` 专注文本场景的复杂倍率（缓存、图像、音频输入、工具附加费）与 OpenRouter/Claude 语义适配。
- 计费表达式层：`tiered_settle.go` 通过 `pkg/billingexpr` 的 `TieredResult` 执行分层表达式计费，`BuildTieredTokenParams` 标准化 P/C/Len 等变量。
- 上游用量适配层：`billing_usage.go` 将 OpenAI/Claude/Gemini 的 BillingUsage 归一化为统一 `dto.Usage`。
- 工具调用计费：`tool_billing.go` 独立计算 web_search/file_search/image_generation 的附加配额。
- 违规扣费：`violation_fee.go` 基于 Grok CSAM 标记在正常流程结束后追加扣费并记录日志。

依赖方向单向向下：本模块调用 `model`、`setting`、`common`、`relay/common`、`pkg/billingexpr`，不被其他 service 反向依赖。所有异步通知（额度不足、性能指标）通过 `gopool.Go` 派发，避免阻塞主路径。
