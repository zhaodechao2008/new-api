本模块由三个独立职责的 service 文件组成，均属于 `package service`：
- `user_notify.go`：实现 `NotifyRootUser`、`NotifyUpstreamModelWatchers`、`NotifyUser` 等入口，按 `userSetting.NotifyType` 分派到 email/webhook/Bark/Gotify 四种通道；非 Worker 模式下通过 `ValidateSSRFProtectedFetchURL` + `GetSSRFProtectedHTTPClient` 做 SSRF 防护，Worker 模式则走 `DoWorkerRequest`。
- `group.go`：基于 `setting.GetUserUsableGroupsCopy()` 和 `ratio_setting` 计算用户可用分组、自动分组、分组启用模型列表及倍率，核心逻辑集中在 `GetUserUsableGroups` 中处理 `+:` / `-:` 特殊规则。
- `funding_source.go`：定义 `FundingSource` 接口（`Source`/`PreConsume`/`Settle`/`Refund`），并提供 `WalletFunding` 和 `SubscriptionFunding` 两个实现，统一抽象预扣费流程；退款通过 `refundWithRetry` 最多重试 3 次，仅用于事务型退款。
依赖方向单向指向 `model`、`dto`、`setting`、`common`，不反向依赖上层 controller。
