- 对外暴露的 service 函数以功能语义命名（如 `NotifyUser`、`GetUserUsableGroups`、`GetUserGroupRatio`），错误通过返回值而非 panic 传播。
- 多通道通知通过 switch 对 `userSetting.NotifyType` 分派，每个通道先校验必要配置为空则直接返回 nil 跳过发送。
- HTTP 出站请求统一在 Worker 与非 Worker 两条路径中实现：Worker 模式走 `DoWorkerRequest`，否则使用 `GetSSRFProtectedHTTPClient` 并先调用 `ValidateSSRFProtectedFetchURL` 进行 SSRF 校验。
- 资金操作采用接口抽象（`FundingSource`）+ 具体实现（`WalletFunding`、`SubscriptionFunding`）模式，`PreConsume`/`Settle`/`Refund` 三方法保持一致签名。
- 幂等性敏感操作（如订阅退款）通过 `requestId` 保证幂等，并结合 `refundWithRetry` 指数退避重试最多 3 次。
- 分组计算优先从 `setting` 包获取只读副本，再通过 `ratio_setting` 叠加用户级特殊规则，避免并发修改共享配置。
