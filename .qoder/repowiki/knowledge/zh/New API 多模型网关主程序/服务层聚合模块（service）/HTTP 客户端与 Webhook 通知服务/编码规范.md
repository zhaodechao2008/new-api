- 所有出站 HTTP 请求统一通过 `GetHttpClient()` 或 `GetSSRFProtectedHTTPClient()` 获取客户端，禁止直接构造 `http.Client`。
- 对可被用户控制的 URL 发起请求前必须调用 `ValidateSSRFProtectedFetchURL` 或通过 `GetSSRFProtectedHTTPClient()` 自动校验，防止 SSRF。
- 代理客户端通过 `proxyHTTPClientCache` 按规范化后的 URL 字符串缓存，使用 `sync.RWMutex` 保护并发访问，并在失效时调用 `CloseIdleConnections` 释放连接。
- 响应体处理遵循先设置 Header 再 WriteHeader 的顺序，且手动设置 Content-Length，确保流式转发时协议正确。
- Webhook 签名采用 HMAC-SHA256 计算 payload 后放入 `X-Webhook-Signature` 请求头，secret 同时作为 Bearer Token 放入 Authorization 头。
