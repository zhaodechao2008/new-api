模块按职责拆分为四个文件：
- `http.go`：纯工具函数，负责优雅关闭响应体、过滤并复制上游响应头（跳过 Content-Length 和 X-Oneapi-Request-Id），以及将字节缓冲写入 Gin Writer 的流式转发。
- `http_client.go`：管理三类 http.Client——全局默认客户端 `httpClient`、SSRF 保护客户端 `ssrfProtectedHTTPClient`、以及按代理 URL 缓存的 `proxyClients`（通过 `proxyHTTPClientCache` 读写锁保护）。所有客户端共享 `newRelayHTTPTransport` 构建的 Transport，并通过 `CheckRedirect` 钩子在重定向时再次校验目标 URL。
- `protected_fetch_client.go`：实现基于 `http.RoundTripper` 的 SSRF 防护层 `ssrfProtectedRoundTripper`，其内部 `protectedFetchDialer` 在拨号前解析域名并调用 `common.SSRFProtection.ValidateNetworkTarget/ValidateResolvedIP` 拦截私有地址与受限端口；按代理 URL 缓存 Transport，避免以用户可控 origin 作为 key 导致 map 膨胀。
- `webhook.go`：封装 WebhookPayload 结构体与 `SendWebhookNotify`，Worker 模式通过 `DoWorkerRequest` 间接发送，非 Worker 模式直接使用 `GetSSRFProtectedHTTPClient()` 并强制走 SSRF 校验。
依赖方向单向向外：本模块依赖 `common`、`logger`、`setting/system_setting`、`dto`，被上层 service 层调用，不反向依赖。
