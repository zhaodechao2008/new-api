本模块位于 service 包内，按功能拆分为四个文件：
- midjourney.go：负责将上游 relayMode 映射到 Midjourney Action，解析 customId 并转换为标准 action（upsample/variation/pan/reroll/zoom/inpaint 等），同时通过 DoMidjourneyHttpRequest 统一构造 HTTP 请求、清理敏感字段（accountFilter/notifyHook）、根据 setting 过滤 prompt 参数，并以超时 context 调用 GetHttpClient()。
- codex_oauth.go：封装 OpenAI auth.openai.com 的 refresh_token 流程，返回 CodexOAuthTokenResult；提供 ExtractCodexAccountIDFromJWT / ExtractEmailFromJWT 从 JWT payload 中解析 claims。
- codex_wham_usage.go：封装 /backend-api/wham/* 三个端点（usage、rate-limit-reset-credits、consume），统一设置 Authorization、chatgpt-account-id、originator 等请求头。
- codex_credential_refresh.go：定义 CodexOAuthKey 结构体与 parseCodexOAuthKey，通过 RefreshCodexChannelCredential 读取 channel.key、调用 OAuth 刷新、回填 AccessToken/RefreshToken/LastRefresh/Expired/AccountID/Email，并写回数据库，支持 ResetCaches 选项重置通道缓存。
依赖方向：本模块依赖 common、constant、dto、model、setting、relayconstant 等上层包，不反向依赖其他 service 文件，各文件之间通过函数调用协作，无全局状态。
