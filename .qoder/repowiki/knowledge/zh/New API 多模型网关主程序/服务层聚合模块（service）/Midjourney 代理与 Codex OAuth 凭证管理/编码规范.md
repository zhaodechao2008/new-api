- 所有对外部 HTTP 调用均通过 http.NewRequestWithContext 创建请求，并显式设置 Timeout 或继承父 context 的超时。
- HTTP 客户端获取统一通过 GetHttpClient() 或 GetHttpClientWithProxy(proxyURL) 包装，避免直接 new(http.Client)。
- 错误返回采用 (statusCode int, body []byte, err error) 三元组形式，由调用方决定如何封装响应。
- 字符串参数在进入业务逻辑前统一进行 strings.TrimSpace 校验空值，并在必要时报错返回。
- JWT 解析采用 base64.RawURLEncoding 手动解码第三段 payload 后 json.Unmarshal 到 map[string]any，再按需提取字段。
- 配置开关通过 setting.* 变量（如 MjAccountFilterEnabled、MjNotifyEnabled、MjModeClearEnabled）在请求处理时动态裁剪请求体。
