- 所有可共享的缓存均通过 sync.Once 初始化并使用全局变量持有，如 getChannelAffinityCache / getChannelAffinityUsageCacheStatsCache，确保单例且线程安全。
- 规则匹配统一采用正则预编译缓存模式：matchAnyRegexCached 将编译后的 *regexp.Regexp 存入 channelAffinityRegexCache sync.Map，避免重复编译。
- 请求上下文传递元数据遵循固定 gin.Key 常量约定（如 ginKeyChannelAffinityCacheKey、ginKeyChannelAffinityMeta、ginKeyChannelAffinityLogInfo），通过 c.Set / c.Get 读写。
- 错误处理与日志记录统一通过 common.SysError / common.SysLog 输出，并在关键路径返回 (value, bool) 或 (value, error) 的双返回值形式表示可选结果。
- 外部 HTTP 调用统一使用 NewProxyHttpClient(channel.GetSetting().Proxy) 创建带代理的 http.Client，并通过 context.WithTimeout 设置超时。
