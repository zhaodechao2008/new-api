- 对外暴露的转换函数均为薄包装，直接委托 `relayconvert` 包实现，本模块只负责参数传递与类型断言（如 `ConvertRequest`、`ClaudeToOpenAIRequest`）。
- Token 计数通过 `constant.*` 全局开关（`CountToken`、`GetMediaToken`、`GetMediaTokenNotStream`）控制行为分支，未启用时直接返回零或默认值。
- OpenAI 文本模型走 `tiktoken-go` 精确计数，非 OpenAI 模型统一走 `EstimateTokenByModel` 按厂商权重估算，由 `CountTextToken` 统一分发。
- 并发安全的共享状态（`tokenEncoderMap`、`multipliersMap`）均通过 `sync.RWMutex` 保护，读取用 RLock，写入前双重检查避免重复创建。
- 模型识别采用 `strings.ToLower(model)` 后以 `strings.Contains` / `strings.HasPrefix` 匹配，而非严格相等比较，以兼容不同命名变体。
