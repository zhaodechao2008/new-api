- 所有认证相关错误通过包级 `var` 定义的 sentinel error（如 ErrLoginSessionInvalid、ErrAuthTokenExpired）表达，并由 `authSessionErrorCode` 统一映射为 HTTP 状态码与错误码字符串。
- 令牌与密钥派生统一通过 `authSigningKey(purpose)` 函数基于 `common.SessionSecret` 和用途字符串计算 HMAC，避免硬编码密钥。
- 对外暴露的敏感元数据（IP、User-Agent）在写入数据库前通过 `truncateAuthMetadata(value, max)` 截断至固定长度。
- 需要鉴权的请求先解析出 `AuthIdentity`，再结合 `model.GetUserSessionCached` 与 `model.GetUserCache` 双重校验用户状态与 AuthVersion，确保会话与用户安全版本一致。
- Refresh Token 刷新采用 `deriveNextRefreshSecret` 滚动派生新 secret 并通过 `RotateUserSessionRefresh` 原子更新，同时处理并发竞态导致的 `ErrRefreshRace`。
