本模块是 Go 包 `service` 的聚合层，所有子功能以独立文件/子目录形式组织并通过包内函数相互调用，而非通过接口或外部依赖注入。
- 入口与装配：各子模块以函数式 API 暴露能力（如 `NewAssetService`、`DisableChannel`、`NotifyRootUser`），由上层 HTTP handler 直接调用，无统一容器或 DI 框架。
- 共享边界：所有子模块共同依赖 `common`、`model`、`dto`、`types`、`setting/operation_setting` 等顶层包，形成隐式契约；错误通过 `types.NewAPIError` 统一包装，日志通过 `common.SysLog` 输出。
- 横向协作模式：例如 channel.go 中的 `DisableChannel`/`EnableChannel` 会调用 user_services 的 `NotifyRootUser`；task_billing.go 串联 billing_quota_usage 的预扣费与结算；conversion_text_token 的转换器被 request_converter.go 统一调度；media_file_services 被 image/audio/file_service 复用。
- 配置来源：多数服务通过 `os.Getenv` 读取环境变量（如 ASSET_ECLOUD_URL/API_KEY），或通过 `GetAssetConfig()` 等工厂函数返回默认值，保持无状态可组合。
