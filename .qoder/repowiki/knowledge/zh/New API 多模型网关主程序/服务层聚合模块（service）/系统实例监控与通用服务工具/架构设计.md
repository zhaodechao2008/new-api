本模块为 service 包内的工具型子集，不定义对外接口，而是被上层 handler/relay 调用：
- system_instance.go：通过 sync.Once + gopool 启动后台 goroutine，按 30s 间隔采集 NodeIdentity、运行时信息（GOOS/GOARCH/StartTime）、主机名及 CPU/Memory/Disk 资源，经 model.UpsertSystemInstance 持久化。
- sensitive.go + str.go：基于 github.com/anknown/ahocorasick 构建 AC 自动机，使用 sync.Map 按字典归一化后的 FNV-64a 哈希缓存 Machine 实例，提供 SensitiveWordContains / SensitiveWordReplace / AcSearch 等多模式匹配与替换能力。
- error.go：集中封装 Midjourney/Claude/OpenAI/Task 等上游错误的统一包装器，并通过 RelayErrorHandler 解析非标准响应体，支持可配置的 StatusCode 映射覆盖。
- log_info_generate.go：围绕 relaycommon.RelayInfo 组装 consume 日志的 other 字段，按文本/WSS/Audio/Claude/Midjourney 分别生成，并注入配额饱和、订阅计费、流式状态、请求转换链等审计信息。
依赖方向单向指向 common、model、dto、logger、types、setting、constant、pkg/billingexpr、relay/common，不反向依赖业务路由层。
