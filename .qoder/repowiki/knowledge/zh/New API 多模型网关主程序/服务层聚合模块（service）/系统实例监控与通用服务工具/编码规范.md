- 对外暴露的错误包装函数统一返回 *dto.XxxErrorWithStatusCode 或 *types.NewAPIError，并在内部对包含 post/dial/http 的网络错误进行脱敏或改写提示。
- AC 自动机通过 getOrBuildAC(dict) 获取，先按归一化+排序+FNV-64a 计算字典 key，再用 sync.Map 缓存 Machine 实例以避免重复构建。
- 日志审计信息通过 appendXxx(relayInfo, other) 系列函数逐步向 map[string]interface{} 注入字段，空值直接跳过不写入。
- 需要幂等执行的后台任务使用 sync.Once 包裹 goroutine 启动逻辑，防止重复注册定时器。
