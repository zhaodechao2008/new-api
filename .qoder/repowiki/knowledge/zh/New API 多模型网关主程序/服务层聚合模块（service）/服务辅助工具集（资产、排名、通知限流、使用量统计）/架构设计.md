本模块所有文件同属 `package service`，作为纯函数式辅助包被上层 handler/controller 调用，不持有 HTTP 路由或中间件逻辑。
- `asset.go`：定义 `AssetConfig` 与 `AssetService` 结构体，通过 `NewAssetService` 从环境变量 `ASSET_ECLOUD_URL` / `ASSET_ECLOUD_API_KEY` 注入配置，`GetAssetConfig` 返回默认白名单扩展名、文件大小上限等常量。
- `rankings.go`：核心是 `GetRankingsSnapshot(period)`，内部通过 `rankingCache` + `sync.Mutex` 实现基于 TTL 的内存缓存；按 period（week/today/month/year）解析时间窗口后调用 `model.GetRankingQuotaTotals/Buckets` 聚合数据，再分别构建模型排行、厂商份额、历史时序与升降榜，并通过 `limitRankedModels`/`limitRankingMovers` 裁剪输出。
- `return_path.go`：极简工具，基于 `system_setting.ServerAddress` 拼接支付回调后缀。
- `usage_helpr.go`：将响应文本通过 `EstimateTokenByModel` 估算 completion token，结合 prompt token 生成 `dto.Usage`，并提供 `ValidUsage` 校验。
- `notify-limit.go`：实现用户级通知频率限制，优先走 Redis（`common.RedisEnabled` 判断），回退到 `sync.Map` 内存存储并启动后台 goroutine 每小时清理过期键；通过 `CheckNotificationLimit(userId, notifyType)` 统一入口暴露。
依赖方向：仅依赖 `model`、`common`、`constant`、`setting/system_setting`、`dto` 等上层包，自身无外部状态持久化（除可选 Redis）。
