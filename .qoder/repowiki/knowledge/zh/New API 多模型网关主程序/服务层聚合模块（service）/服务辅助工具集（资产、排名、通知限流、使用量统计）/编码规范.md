- 对外暴露的公共函数采用首字母大写的导出形式，内部辅助函数统一小写命名并按职责拆分为独立函数（如 `buildRankedModels`、`buildVendorShareHistory` 等）。
- 可配置项通过结构体字段 + `NewXxxService` 构造函数注入，未显式传入时回退读取 `os.Getenv` 环境变量（如 AssetService）。
- 共享状态使用包级变量配合 `sync.Mutex` 或 `sync.Map` 保护，并通过 `sync.Once` 确保一次性初始化（如 rankingCache、notifyLimitStore 清理任务）。
- 数值计算结果统一通过 `roundRankingFloat` 等专用舍入函数处理，避免直接对 float64 做格式化。
- 常量集中以包级 `const` 块声明（如 `rankingCacheTTL`、`NotifyLimitCount`），便于跨文件复用与调整阈值。
