- 所有外部 URL 访问统一经过 `DoDownloadRequest`，并在非 Worker 模式下通过 `ValidateSSRFProtectedFetchURL` 或 `common.ValidateURLWithFetchSetting` 做 SSRF 防护。
- 大对象优先使用 `types.CachedFileData` 的内存/磁盘双层缓存策略，通过 `shouldUseDiskCache` 阈值判断是否落盘，并在 `OnClose` 回调中更新磁盘文件计数。
- MIME 类型检测采用多级回退策略：Content-Type → Content-Disposition filename → URL 扩展名 → `http.DetectContentType` → 图片格式解码 → 最终 `application/octet-stream`。
- 图片解码统一通过 `decodeImageConfig` / `getImageConfig` 依次尝试标准库 image、webp、HEIF/HEIC（魔数+ispe box 解析），失败返回明确错误而非静默忽略。
- 请求级资源清理通过 `registerSourceForCleanup` 将 FileSource 注册到 gin.Context 的固定 key，由 `CleanupFileSources` 在中间件层统一调用释放。
- 调试日志通过 `common.DebugEnabled` 开关包裹 `logger.LogDebug`，避免生产环境输出敏感信息。
