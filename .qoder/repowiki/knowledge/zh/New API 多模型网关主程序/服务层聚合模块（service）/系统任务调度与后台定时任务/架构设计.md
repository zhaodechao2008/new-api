模块以 `system_task.go` 为核心，定义 `SystemTaskHandler` 与 `ScheduledSystemTaskHandler` 两个接口，通过全局 `systemTaskHandlers` 注册表 + `RegisterSystemTaskHandler` 实现插件式扩展；`StartSystemTaskRunner` 仅在 master 节点启动单例 runner，按固定间隔轮询 pending 任务并调用 `model.ClaimSystemTask` 加分布式锁，使用 `runWithLeaseHeartbeat` 周期性续租防止长时间任务被误判过期。
- `task.go` 仅提供平台名到模型名的转换工具函数。
- `subscription_reset_task.go` 与 `codex_credential_refresh_task.go` 是独立的后台 goroutine 任务，各自通过 `sync.Once` 保证单例启动，使用 `atomic.Bool` 防止重入，按 ticker 周期批量处理数据库记录。
- 依赖方向单向指向 `model`、`common`、`logger`、`constant`，不反向依赖上层业务。
