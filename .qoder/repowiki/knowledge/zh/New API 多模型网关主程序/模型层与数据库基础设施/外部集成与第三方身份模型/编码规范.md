- 所有持久化结构体均通过 gorm tag 声明表名、字段类型、索引与约束，并通过 TableName() 方法显式指定表名。
- CRUD 操作以包级函数形式暴露（如 GetAllXxx、GetXxxById、CreateXxx），对实体对象则提供 Insert/Update/Delete 方法。
- 需要并发安全的写入通过事务参数 *gorm.DB 传递（如 ClaimExternalIdentityWithTx、ReleaseExternalIdentityWithTx），并在内部做空值校验后返回 errors.New。
- 唯一性/冲突检测优先使用数据库层约束（uniqueIndex、OnConflict DoNothing）而非应用层 check-then-update，失败时回退为 ErrRecordNotFound 或自定义错误。
- 字符串字段在入库前统一做 strings.TrimSpace 与大小写规范化（如 slug 强制小写 + 字母数字连字符）。
- 查询函数普遍采用链式 Where().Order().Limit().Offset().Find() 模式，分页参数通过结构体（TaskQueryParams）集中传入。
