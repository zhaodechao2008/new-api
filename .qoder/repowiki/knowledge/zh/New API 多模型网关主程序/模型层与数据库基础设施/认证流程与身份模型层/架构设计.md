本模块为 `model` 包下的安全相关领域模型集合，所有文件同属 `package model`，通过共享的 `DB` 全局实例和 `lockForUpdate`、`IncrementUserAuthVersionWithTx`、`PublishUserAuthCache` 等跨文件函数协作。
- `auth_flow.go`：实现一次性认证流程（OAuth/2FA/Passkey/Telegram），使用 HMAC(token) + `token_hash` 唯一索引保证防重放，提供 `CreateAuthFlow`、`GetAuthFlow`、`ConsumeAuthFlowWithAction` 以及外部断言的 `ClaimExternalAuthAssertion` 原子消费接口。
- `passkey.go`：基于 `go-webauthn/webauthn` 库封装 Passkey 凭据的注册、断言、更新与删除，敏感字段以 base64 存储，并通过 `ToWebAuthnCredential` / `NewPasskeyCredentialFromWebAuthn` 在持久化结构与 WebAuthn 协议对象间转换。
- `twofa.go`：实现 TOTP 双因素认证与备用码机制，包含失败次数累加、锁定窗口、启用/禁用/替换备用码等状态机操作，所有变更安全点的 API 均通过 `IncrementUserAuthVersionWithTx` 提升用户 auth_version 并调用 `PublishUserAuthCache` 失效缓存。
- `authz_role.go` 与 `casbin_rule.go`：分别定义角色表与 Casbin 策略表结构，配合上层权限引擎使用。
依赖方向单向向下：本模块仅依赖 `common` 包中的加密/序列化工具与 `gorm.io/gorm`，不反向依赖业务逻辑层。
