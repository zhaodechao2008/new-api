- 所有需要并发安全的写操作都通过 `DB.Transaction` 包裹，并在查询前使用 `lockForUpdate(tx)` 行级锁防止竞态。
- 修改用户安全相关状态（启用/禁用 2FA、替换备用码、更新 Passkey）时统一调用 `IncrementUserAuthVersionWithTx` 提升 auth_version，随后调用 `PublishUserAuthCache` 使旧会话失效。
- 对外暴露的错误采用预定义错误变量（如 `ErrAuthFlowInvalid`、`ErrPasskeyNotFound`、`ErrTwoFANotEnabled`），并将数据库 `gorm.ErrRecordNotFound` 转换为语义化错误返回。
- 敏感字段（TokenHash、Secret、CodeHash、CredentialID、PublicKey、AAGUID）一律通过 base64 或 HMAC 编码后存储，JSON tag 标记为 `-` 避免泄露给前端。
- 模型结构体统一实现 `TableName()` 方法指定表名，并使用 GORM tag 声明主键、索引、唯一约束与时间戳自动填充。
