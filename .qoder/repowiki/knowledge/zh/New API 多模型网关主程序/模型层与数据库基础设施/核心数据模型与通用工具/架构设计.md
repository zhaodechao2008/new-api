本模块是 model 包的基础层，不依赖上层业务逻辑，仅依赖 common、constant、dto 等基础包。结构分为四类：
- 实体模型：`model_meta.go` 中的 `Model`（含 Insert/Update/Delete/SearchModels 等 CRUD），`ability.go` 中的 `Ability`（多对多关联 Channel 的能力表，提供 GetChannel 按优先级+权重随机选择通道），`asset.go` 中的 `AssetGroup`/`Asset`。
- 基础设施：`db_time.go` 提供跨 PostgreSQL/SQLite/MySQL 的数据库时间获取；`locking.go` 封装 SELECT ... FOR UPDATE，SQLite 下自动跳过；`errors.go` 集中定义 ErrDatabase、ErrInvalidCredentials 等全局错误变量。
- 缓存与批处理：`utils.go` 实现基于内存 map + sync.Mutex 的批量更新器（用户配额、Token 配额、渠道用量等），通过 gopool 后台协程定时 flush；`model_extra.go` 通过 `modelEnableGroupsLock` 读写保护模型启用分组与计费类型的内存缓存。
- 辅助查询：`missing_models.go` 对比已启用模型与元数据表返回缺失模型名。
所有 DB 操作统一通过包级 `DB` 变量访问，事务由调用方传入或内部 Begin/Commit。
