- CRUD 方法直接操作包级 `DB` 变量，并返回 error，不在返回值中包裹自定义错误类型。
- 需要并发安全的写操作使用 `sync.Mutex` 或 `sync.RWMutex` 保护内存 map（如 `batchUpdateLocks`、`modelEnableGroupsLock`）。
- 批量写入采用 `lo.Chunk(..., 50)` 分片后配合 `clause.OnConflict{DoNothing: true}` 去重插入。
- 数据库特定语法通过 `common.UsingMainDatabase` 判断（如 SQLite 跳过 FOR UPDATE、TRUNCATE 改用 DELETE FROM）。
- 分页查询统一返回 `(list []T, total int64, err error)` 三元组，先 Count 再 Offset/Limit Find。
