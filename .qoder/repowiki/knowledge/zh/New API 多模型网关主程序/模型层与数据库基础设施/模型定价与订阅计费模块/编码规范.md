- 所有对外暴露的只读缓存函数（如 `GetPricing`、`GetVendors`）均采用「时间戳 + 长度检查」的双检模式配合互斥锁，确保高并发下的惰性刷新与线程安全。
- 数据库写操作统一通过 `DB.Transaction` 包裹，并在需要行级锁的场景使用 `lockForUpdate(tx)` 显式加锁，错误通过预定义变量（如 `ErrSubscriptionOrderNotFound`）返回。
- 实体结构体实现 `BeforeCreate` / `BeforeUpdate` GORM 钩子以自动填充 `CreatedAt`、`UpdatedAt` 等时间戳字段，保持数据一致性。
- 可配置常量（如订阅时长单位、重置周期、缓存 TTL/容量）集中定义为包级常量或环境变量读取函数，避免硬编码散落在业务逻辑中。
- 测试用例通过 `t.Helper()` 封装建表、插入、清理等重复步骤，并使用 `require.NoError` 与 `assert.Equal` 断言，保证测试可维护性。
