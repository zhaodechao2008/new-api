- 日志写入统一通过 `createLog` 封装，先调用 `ensureLogRequestId` 回填 RequestId，再写入 `LOG_DB`，错误统一走 `common.SysLog` 或 `logger.LogError` 记录。
- 文本模糊搜索通过 `applyExplicitLogTextFilter` + `buildLogLikeCondition` 路由到不同数据库的 LIKE 转义策略（标准 ESCAPE '!' vs ClickHouse 反斜杠转义）。
- 对 ClickHouse 的特殊处理集中在 `common.UsingLogDatabase(common.DatabaseTypeClickHouse)` 分支内，包括排序、ID 分配、TTL 表达式与删除语句。
- 敏感字段在返回前剥离：`formatUserLogs` 会删除 `admin_info`、`audit_info`、`stream_status` 等字段后再序列化到 `Other`。
- 签到操作按数据库类型分派：SQLite 走无事务顺序路径并手动回滚，MySQL/PostgreSQL 走 GORM 事务路径，保证并发下 `(user_id, checkin_date)` 唯一约束生效。
