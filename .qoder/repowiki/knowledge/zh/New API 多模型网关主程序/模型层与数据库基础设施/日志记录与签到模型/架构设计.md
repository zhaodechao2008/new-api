本模块由两个独立的数据域组成：
- `log.go` 定义 `Log` 结构体及所有日志写入/查询入口（`RecordLog`、`RecordConsumeLog`、`RecordErrorLog`、`GetAllLogs`、`GetUserLogs`、`SumUsedQuota` 等），统一通过 `LOG_DB` 访问日志库；当 `common.UsingLogDatabase(DatabaseTypeClickHouse)` 为真时，使用 ClickHouse 特定的 LIKE 转义、排序 (`clickHouseLogOrder`)、TTL 表达式与 `ALTER TABLE ... DELETE` 删除策略。
- `checkin.go` 定义 `Checkin` 签到模型，针对 SQLite 不支持嵌套事务的特性，分别实现 `userCheckinWithTransaction`（MySQL/PostgreSQL）和 `userCheckinWithoutTransaction`（SQLite）两条路径，并在成功后异步调用 `cacheIncrUserQuota` 更新缓存。
- 两者都依赖 `common` 包获取时间戳、节点名、日志开关、数据库类型判断等全局配置，并通过 `gorm.io/gorm` 进行 ORM 操作。
- `clickhouse_log_test.go` 集中测试 ClickHouse DSN 识别、DSN 规范化、TTL 表达式生成、建表 SQL 片段以及 LIKE 条件构建在不同数据库下的行为差异。
