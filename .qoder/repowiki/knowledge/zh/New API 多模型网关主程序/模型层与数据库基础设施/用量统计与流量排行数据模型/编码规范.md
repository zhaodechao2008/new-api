- 对高写频的统计写入采用内存 map + sync.Mutex 缓冲，再批量 Upsert 到数据库，避免每次请求都落盘。
- GORM 查询统一通过 `DB.Table("表名")` 直接构造，字段通过 struct tag 或 Select 指定，不使用 ORM 关联模型。
- 需要回填关联名称（TokenName、ChannelName）时，先收集 ID 去重集合，再一次性 IN 查询构建 map 回填，减少 N+1 查询。
- 按时间范围过滤统一通过传入 startTime/endTime 参数并在查询末尾追加 Where 条件，支持可选生效。
- 数据库方言差异通过 `common.UsingMainDatabase` 判断后选择不同 SQL 表达式（如 MySQL 用 FLOOR，PostgreSQL 用整数除法）。
