本模块围绕 `quota_data` 表提供三类能力：
- 数据采集与持久化（usedata.go）：通过 `LogQuotaData` 将请求按小时对齐后写入内存 `CacheQuotaData` map，由 `UpdateQuotaData` 定时任务在 `common.DataExportEnabled` 开启时调用 `SaveQuotaDataCache` 批量 Upsert（存在则 `increaseQuotaData` 原子累加 count/quota/token_used，不存在则插入），并使用 `sync.Mutex` 保证并发安全。
- 流量明细查询（usedata_flow.go）：`GetFlowQuotaData` 根据 `role` 分派到 `getSelfFlowQuotaData` / `getAdminFlowQuotaData` / `getRootFlowQuotaData`，分别按 token_id、user+channel、node+token+channel 等维度聚合；再通过 `fillFlowTokenNames` 和 `fillFlowChannelNames` 批量回填 Token/Channel 名称，其中 ChannelName 优先走 `MemoryCacheEnabled` 下的 `CacheGetChannel` 缓存，否则回退到直接查 channels 表。
- 模型使用排行（usedata_rankings.go）：提供总量排行 `GetRankingQuotaTotals` 与按时间桶聚合的 `GetRankingQuotaBuckets`，后者通过 `rankingBucketExpr` 根据 MySQL/其他数据库方言生成不同的取整表达式。
所有查询均通过 GORM 的 `DB.Table("quota_data")` 直接操作，不依赖 ORM 映射结构体，体现以 SQL 为中心的数据访问风格。
