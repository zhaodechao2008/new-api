本模块以 GORM 模型为核心，按职责拆分为四个文件：
- `user.go`：定义 `User` 结构体及其 CRUD、邮箱唯一性校验（含 PostgreSQL advisory lock / MySQL FOR UPDATE 的 `withNormalizedEmailLock`）、软删除与硬删除、AuthVersion 递增与会话吊销联动。
- `user_cache.go`：维护 `UserBase` 在 Redis hash 中的缓存，通过 `AuthVersion` + schema version 做一致性围栏，提供增量字段更新与配额原子操作。
- `user_session.go`：实现 `UserSession` 短生命周期会话，包含基于 HMAC 的 refresh token 轮换、并发安全刷新、批量吊销、过期清理，并通过 Lua 脚本在 Redis 中写带 TTL 的 deny fence。
- `user_oauth_binding.go`：管理用户与自定义 OAuth 提供商的多对一绑定关系。
测试文件覆盖认证流程、会话 TTL/Lua 行为、分页、迁移及缓存版本一致性，均使用 `miniredis` 或注入失败 Redis 客户端模拟外部依赖。
