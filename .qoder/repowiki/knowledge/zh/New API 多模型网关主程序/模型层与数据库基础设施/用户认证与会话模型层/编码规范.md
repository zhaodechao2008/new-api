- 所有涉及认证敏感状态变更的操作都会递增 `AuthVersion`，并在变更后调用 `RevokeAllUserSessions` 或发布 tombstone 使旧会话失效。
- 数据库写操作统一包裹在 `DB.Transaction(func(tx *gorm.DB) error {...})` 中，并通过 `lockForUpdate` 或 `withNormalizedEmailLock` 保证并发安全。
- Redis 读写前检查 `common.RedisEnabled`，未启用时直接跳过缓存逻辑，保证功能降级可用。
- 缓存条目携带 `CacheSchema` 版本号，读取时校验版本匹配，否则视为 stale 并回退到数据库。
- 错误类型集中定义为包级变量（如 `ErrUserSessionInvalid`、`ErrEmailAlreadyTaken`），便于上层判断。
- 对外暴露的函数同时提供 `WithTx` 变体，以便在更大事务中复用同一 gorm.DB 实例。
