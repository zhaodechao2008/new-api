本模块包含两类独立的任务模型：
- `task.go` 定义 `Task` 结构体及其 JSON 字段（`Data`、`Properties`、`PrivateData`），通过实现 `driver.Valuer`/`sql.Scanner` 完成 MySQL JSON 列映射；提供 `InitTask` 构造器、按用户/全局的查询函数、`UpdateWithStatus` CAS 更新、`ClaimQuotaForRefund`/`RestoreQuotaAfterFailedRefund` 原子配额标记，以及 `HasUnfinishedSyncTasks`/`HasTaskPollingWork` 等轻量存在性检查供调度器决策。
- `system_task.go` 定义 `SystemTask` 与 `SystemTaskLock` 两张表，通过 `BeforeCreate` 钩子填充时间戳，使用 `active_key`（唯一索引）防止同类型任务重复激活，并通过独立的 `system_task_locks` 表实现基于 `locked_until` 的租约式分布式锁，配合 `ClaimSystemTask`、`UpdateSystemTaskState`、`RenewSystemTaskLock`、`FinishSystemTask` 构成完整的 claim-renew-finish 生命周期。
- 依赖方向单向指向 `common`、`constant`、`dto`、`relay/common`，不反向依赖上层业务；测试通过 `task_cas_test.go` 中的 `TestMain` 初始化内存 SQLite 并 AutoMigrate 所有相关表，`truncateTables` 统一清理数据。
