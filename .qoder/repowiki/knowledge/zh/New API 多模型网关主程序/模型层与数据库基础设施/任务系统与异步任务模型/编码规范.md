- GORM 模型通过实现 `Scan`/`Value` 方法将自定义结构体序列化为 JSON 存入数据库（如 `Properties`、`TaskPrivateData`）。
- 并发安全的状态更新采用 CAS 模式：`UpdateWithStatus` 以 `fromStatus` 作为 WHERE 条件，`ClaimQuotaForRefund`/`RestoreQuotaAfterFailedRefund` 以 `quota` 值作为乐观锁标志位。
- 系统任务的生命周期通过独立的 `SystemTaskLock` 表管理租约，所有写操作（`UpdateSystemTaskState`、`FinishSystemTask`、`RenewSystemTaskLock`）都同时校验 `status=running`、`locked_by` 和 `locked_until >= now`。
- 查询函数统一返回 `([]*Task, error)` 或 `(*Task, bool, error)` 形式，并通过 `RecordExist` 包装 GORM 错误判断记录是否存在。
- 任务状态以字符串常量集中定义在文件顶部（`TaskStatus*`、`SystemTaskStatus*`、`SystemTaskType*`），并通过方法转换到外部 DTO 状态。
