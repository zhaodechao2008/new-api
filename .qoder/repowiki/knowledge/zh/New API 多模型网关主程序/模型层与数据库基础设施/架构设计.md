本模块以 `main.go` 中的 `DB` 和 `LOG_DB` 两个全局 GORM 实例为核心，通过环境变量 `SQL_DSN` / `LOG_SQL_DSN` 动态选择主库与日志库（支持 MySQL、PostgreSQL、SQLite、ClickHouse），并在启动时执行 `InitDB()` → `migrateDB()` / `migrateLOGDB()` 完成表结构自动迁移与 ClickHouse TTL 同步。各子模块（user_auth、channel、task_system、pricing_subscription、payment_topup_redemption、usage_data、auth_identity、external_integrations、system_config、logging、core_models）仅依赖本模块暴露的 GORM 模型结构与 DB/LOG_DB 连接，不直接操作底层驱动；跨模块共享的基础设施包括：`commonGroupCol`/`commonKeyCol` 等方言列名适配、`db_time.go` 的时间获取、`errors.go` 的错误常量、`locking.go` 的行级锁封装、`model_meta.go` 的元数据以及 `setup.go` 的系统初始化状态。所有模型在 `migrateDB()` 中集中声明式 AutoMigrate，确保 schema 变更由单一入口维护。
