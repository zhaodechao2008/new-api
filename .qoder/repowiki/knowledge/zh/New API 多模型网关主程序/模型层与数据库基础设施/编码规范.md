- 所有 GORM 模型通过 `migrateDB()` 集中注册 AutoMigrate，新增实体必须在此处声明
- 数据库方言差异通过 `initCol()` 初始化的 `commonGroupCol`/`commonKeyCol`/`commonTrueVal` 等变量统一抽象
- 主库与日志库分离：主库由 `SQL_DSN` 控制，日志库由 `LOG_SQL_DSN` 控制，未设置时日志库复用主库
- MySQL 连接强制追加 `parseTime=true`，PostgreSQL 使用 `PreferSimpleProtocol: true` 禁用隐式预编译
- 所有模型字段使用 GORM tag 标注类型与约束，时间字段统一通过 `db_time.go` 提供的工具函数处理
