本模块以 `model/main.go` 为入口，集中管理 GORM 全局连接 `DB` 与 `LOG_DB`，通过 `chooseDB` 根据环境变量 `SQL_DSN`/`LOG_SQL_DSN` 自动选择 SQLite、MySQL、PostgreSQL 或 ClickHouse（仅日志），并在 `InitDB`/`InitLogDB` 中完成连接池参数设置、字符集校验与 `AutoMigrate`。
- `option.go`：定义 `Option` 键值对模型，维护内存中的 `common.OptionMap` 作为运行时配置缓存；`InitOptionMap` 从各 setting 包导出默认值，`UpdateOption`/`UpdateOptionsBulk` 原子写入 DB 并回写内存，`SyncOptions` 定时轮询增量同步。
- `frontend_option_migration.go`：针对已移除的前端 dashboard 的遗留配置（ApiInfo、Announcements、FAQ、UptimeKumaUrl/Slug、theme.frontend）执行单向迁移到 `console_setting.*` 命名空间，每个迁移在独立事务中执行，失败不阻塞其他项。
- `system_instance.go`：通过 `SystemInstance` 记录节点心跳，使用 `UpsertSystemInstance` + `OnConflict` 实现幂等上报，`DeleteStaleSystemInstances` 按 `last_seen_at` 清理过期节点。
- `setup.go`：`Setup` 表标记系统是否已完成初始化，`CheckSetup` 结合是否存在 root 用户决定 `constant.Setup` 标志。
依赖方向：本模块依赖 `common`、`setting/*`、`constant` 等上层包读取配置值，但不被业务逻辑直接依赖——由应用启动流程调用 InitDB/InitOptionMap 完成初始化。
