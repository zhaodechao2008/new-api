- 所有运行时配置更新先落库再回写 `common.OptionMap`，并通过 `updateOptionMap` 统一分发到对应业务变量，保证内存与 DB 一致。
- 数据库操作统一通过包级 `DB`/`LOG_DB` 全局变量访问，避免传入 gorm.DB 实例，简化调用方代码。
- 迁移函数采用单事务包裹单个 key 的读写，失败时记录错误但继续处理后续项，最终用 `errors.Join` 汇总返回。
- 字段类型在 MySQL/PostgreSQL/SQLite 之间通过 `initCol` 中的反引号/双引号及 true/false 常量差异进行适配。
- 配置项键名采用点号分层命名（如 `console_setting.api_info`、`performance_setting.xxx`），由 `handleConfigUpdate` 统一路由到对应配置对象。
