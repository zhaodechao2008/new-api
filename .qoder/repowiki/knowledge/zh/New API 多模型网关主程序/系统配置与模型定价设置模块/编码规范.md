- 每个配置结构体以 `defaultXxxSettings` 变量定义默认值，再通过包级变量 `xxxSettings = defaultXxxSettings` 暴露可修改实例，并在 `init()` 中调用 `config.GlobalConfig.Register("模块名", &xxxSettings)` 注册。
- 配置结构体字段统一使用 `json:"tag_name"` 标签作为持久化键名，未导出字段被反射跳过。
- 比率/价格类配置使用 `types.NewRWMap[string, float64]` 存储，并提供 `*2JSONString()` 导出与 `Update*ByJSONString(jsonStr)` 热更新接口，更新时通过回调函数失效相关缓存。
- 读取配置统一通过 `GetXxxSetting() *XxxSetting` 返回指针形式，避免拷贝导致状态不一致。
