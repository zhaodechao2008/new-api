模块以 `config/config.go` 中的 `ConfigManager` 为核心，通过反射将任意结构体序列化为扁平的 `key=value` 键值对（前缀为模块名），实现配置的统一加载（`LoadFromDB`）与保存（`SaveToDB`）。各子目录按职责划分：
- `model_setting/`：定义各模型供应商（claude、gemini、grok、qwen）及全局 `GlobalSettings` 的结构体，在 `init()` 中调用 `config.GlobalConfig.Register("global"|"gemini"|... , &xxx)` 完成注册。
- `operation_setting/`：包含站点运行开关、自动禁用关键词、监控、配额、支付等运行时开关，部分通过包级变量直接暴露（如 `DemoSiteEnabled`）。
- `ratio_setting/`：维护模型倍率、价格、缓存、图片、音频等多张 `types.RWMap` 并发安全映射，提供 `InitRatioSettings()` 初始化并支持 JSON 字符串热更新。
- `system_setting/`、`console_setting/`、`billing_setting/`、`perf_metrics_setting/`、`performance_setting/`：各自定义独立配置结构并通过 `init()` 注册到 `GlobalConfig`。
- 根目录下 `chat.go`、`midjourney.go`、`rate_limit.go`、`sensitive.go`、`payment_*.go`、`user_usable_group.go`、`auto_group.go`、`reasoning/suffix.go` 等为特定业务场景的配置或常量。
依赖方向单向指向 `config` 包，子模块之间不互相依赖，保证配置解耦。
