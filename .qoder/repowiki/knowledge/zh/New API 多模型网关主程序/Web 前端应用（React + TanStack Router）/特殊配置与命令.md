开发：`npm run dev`（Rsbuild dev server，代理 /api、/mj、/pg）；构建：`npm run build` 或 `npm run build:check`（先 tsgo -b 类型检查）；代码质量：`npm run lint`（oxlint）、`npm run format`（自定义脚本维护保护头）、`npm run copyright`（批量添加版权头）、`npm run i18n:sync`（同步多语言键）；预览：`npm run preview`。依赖 Node 版本由 `.node-version` 指定，包管理器使用 Bun（`bun.lock`）。
