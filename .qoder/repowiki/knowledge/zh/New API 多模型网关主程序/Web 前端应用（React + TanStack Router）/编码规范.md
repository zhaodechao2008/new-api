- 每个业务 feature 目录统一包含 `index.tsx`、`api.ts`、`types.ts`、`constants.ts`，以及可选的 `components/`、`hooks/`、`lib/` 子目录，形成自包含的功能模块。
- 所有 HTTP 请求通过 `@/lib/http-client` 的 `api` 实例发起，并在 `@/lib/api.ts` 中集中 re-export 认证相关函数，避免直接 import http-client。
- 路由文件按 TanStack Router 约定放置在 `src/routes/` 下，使用括号分组 `(auth)`、`(errors)`、`_authenticated` 表达权限与布局约束，根路由 `__root.tsx` 统一注入全局 Provider。
- 组件采用 shadcn/ui 风格，通过 `components.json` 配置的别名（`@/components`、`@/ui`、`@/lib`、`@/hooks`）进行导入，图标统一使用 Hugeicons。
- 国际化文案通过 `react-i18next` 的 `t()` 函数访问，多语言键集中在 `i18n/locales/*.json`，新增键需通过 `scripts/sync-i18n.mjs` 保持同步。
- 文件顶部强制保留 AGPLv3 版权头，通过 `scripts/add-copyright.mjs` 批量添加，格式校验由 `format-with-protected-headers.mjs` 保证。
