- 每个功能域通过独立的 `SetXxxRouter(*gin.Engine)` 函数暴露，函数内部使用 `router.Group("/前缀")` 划分命名空间并串联中间件。
- 路由注册采用 `Group` + `{}` 闭包块的形式声明所有路径，便于在同一作用域内复用相同的中间件链。
- 鉴权通过 `middleware` 包的 `UserAuth`、`AdminAuth`、`RootAuth`、`TokenAuth`、`TokenOrUserAuth` 等中间件组合实现，敏感操作额外叠加 `CriticalRateLimit`、`DisableCache`、`TurnstileCheck`。
- 每条路由通过 `middleware.RouteTag("api"|"relay"|"web"|"old_api")` 标注来源，便于统计与日志追踪。
- 对外部第三方回调（Stripe、Creem、Waffo、Epay 等）统一使用 `anonymousRequestBodyLimit` 中间件限制请求体大小，避免未认证请求滥用。
- 测试通过构造空 `gin.Engine`、调用对应 `SetXxxRouter` 后遍历 `engine.Routes()` 断言路由存在性与权限映射，而非集成测试。
