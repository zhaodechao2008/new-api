该模块为纯脚本集合，无代码依赖：
- `migration_v0.2-v0.3.sql` 和 `migration_v0.3-v0.4.sql` 是按语义化版本号命名的增量迁移文件，分别负责从 v0.2→v0.3（合并 tokens 剩余配额到 users.quota）和 v0.3→v0.4（为渠道生成 abilities 记录）的单向数据变更。
- `time_test.sh` 是独立的可执行 Shell 脚本，通过 curl 循环调用 `/v1/chat/completions` 接口，使用 `bc` 计算总耗时、平均值与标准差，作为外部性能基准工具。
- 三者之间无相互引用，均直接操作项目数据库或远程 HTTP API，属于零耦合的辅助脚本目录。
