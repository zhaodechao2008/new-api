应用启动必须先调用 `common.InitEnv()` 以解析 flag 和环境变量，再调用 `common.InitRedisClient()` 建立 Redis 连接；可通过 `--port`、`--log-dir`、`--version`、`--help` 控制进程行为，关键环境变量包括 `SESSION_SECRET`、`CRYPTO_SECRET`、`REDIS_CONN_STRING`、`SYNC_FREQUENCY`、`TLS_INSECURE_SKIP_VERIFY`、`SMTP_*`、`GLOBAL_API_RATE_LIMIT_*`、`CRITICAL_RATE_LIMIT_*`、`SEARCH_RATE_LIMIT_*` 等。
