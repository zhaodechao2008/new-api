- 所有运行期配置均通过 `GetEnvOrDefault*` 系列函数从环境变量注入到 `constants.go` 中的全局变量，避免直接 `os.Getenv` 散落各处。
- 错误返回统一使用 `github.com/pkg/errors` 包装，并通过 `IsRequestBodyTooLargeError` 等专用判断函数区分错误类型。
- Gin 上下文数据存取通过 `SetContextKey`/`GetContextKey` 系列函数进行，key 统一来自 `constant.ContextKey` 枚举并以字符串形式存入 gin.Context。
- 需要多次读取的请求体一律通过 `GetBodyStorage` 获取 `BodyStorage` 接口，并在请求结束时调用 `CleanupBodyStorage` 释放资源。
- Redis 操作在 Debug 模式下统一打印 key 与参数，且对带 TTL 的键在执行 INCR/HINCRBY/HSET 后通过事务重新设置过期时间。
- 可选配置项通过函数式 Option 模式传递（如 `limiter.Option` 的 `WithCapacity`/`WithRate`/`WithRequested`），默认值在函数内部构造。
