本模块是 NewAPI 的共享基础包，按职责拆分为多个单文件 Go 源：
- 启动与配置：`init.go` 通过 `flag` 解析命令行参数并统一从环境变量注入所有运行期变量（如 `SESSION_SECRET`、`REDIS_CONN_STRING`、各类 rate limit 开关），`constants.go` 集中声明全局常量与默认值；`env.go` 提供 `GetEnvOrDefault*` 系列辅助。
- Gin 集成层：`gin.go` 封装 `ApiSuccess`/`ApiError`/`ApiErrorI18n` 等统一响应格式，并通过 `KeyBodyStorage` 在 gin.Context 中缓存可重复读取的请求体。
- 请求体存储抽象：`body_storage.go` 定义 `BodyStorage` 接口（内存 `memoryStorage` 与磁盘 `diskStorage` 两种实现），由 `CreateBodyStorageFromReader` 根据大小阈值自动选择，配合 `disk_cache.go` 统一管理临时文件生命周期。
- Redis 客户端：`redis.go` 暴露 `RDB` 全局实例及 `RedisSet/Get/HSetObj/HGetObj/Incr` 等封装，`limiter/` 子包基于 go-redis 执行 Lua 脚本实现分布式令牌桶限流。
- 系统能力：`system_monitor_*` 按平台拆分 Unix/Windows 监控指标，`gopool.go` 封装 bytedance/gopool 作为统一 goroutine 池，`database.go`/`quota.go`/`crypto.go`/`email*.go`/`totp.go`/`url_validator.go`/`ssrf_protection.go` 等各自负责一个横切能力。
- 依赖方向：本模块被上层 handler/service 依赖，自身仅依赖 `github.com/QuantumNous/new-api/constant` 中的上下文键常量，不反向依赖业务路由或控制器。
