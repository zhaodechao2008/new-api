该包为纯常量包，遵循 README.md 中约定的单向依赖：仅允许 import Go 标准库，禁止引用项目内其他自定义包，从而避免循环依赖。
- 枚举与类型定义：通过自定义 string/int 类型（如 `ContextKey`、`TaskPlatform`、`MultiKeyMode`、`EndpointType`）配合 `const` 块组织 API 类型、渠道类型、任务平台、支付方法等枚举。
- 映射表集中管理：`channel.go` 中的 `ChannelBaseURLs`、`ChannelTypeNames`、`ChannelSpecialBases`；`midjourney.go` 的 `MidjourneyModel2Action`；`task.go` 的 `SunoModel2Action` 等，均使用 map/slice 将模型/动作/BaseURL 进行集中映射。
- 运行时可写变量：`env.go` 暴露一组 package-level 变量（如 `StreamingTimeout`、`DifyDebug`、`TrustedRedirectDomains` 等），由启动阶段注入；`setup.go` 的 `Setup` 标志用于标识初始化状态。
- 领域常量分组：按文件划分 Azure 时间戳、缓存键格式、FinishReason、Waffo 支付方式等，每个文件聚焦一个子域，便于新增时保持单一职责。
