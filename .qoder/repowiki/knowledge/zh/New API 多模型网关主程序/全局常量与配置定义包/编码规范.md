- 枚举类型优先使用自定义 string 或 int 类型（如 `ContextKey`、`TaskPlatform`、`EndpointType`）配合 const 块声明，而非裸字符串或 int。
- 平台/模型到动作或 BaseURL 的映射统一以包级 map/slice 变量集中管理（如 `ChannelTypeNames`、`MidjourneyModel2Action`、`SunoModel2Action`）。
- 运行时可配置的全局变量集中在 `env.go` 中以 package-level var 暴露，由外部启动流程注入，包内不执行赋值逻辑。
- 每个文件聚焦单一领域（Azure、缓存键、渠道、上下文键、任务、Midjourney、支付等），并通过文件名明确语义。
- 在 iota 枚举末尾保留 Dummy 占位常量（如 `APITypeDummy`、`ChannelTypeDummy`）用于计数，禁止在其后追加新值。
