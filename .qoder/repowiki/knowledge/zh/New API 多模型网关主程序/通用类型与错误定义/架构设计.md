本模块是纯类型定义包（package types），不包含业务逻辑，仅对外暴露结构体、接口、常量与辅助函数，供 common、relay、channel 等上层模块复用。
- 错误体系：error.go 定义了 NewAPIError、OpenAIError、ClaudeError 三种错误类型及 ErrorType/ErrorCode 枚举，通过 WithXxx / NewXxx 构造函数 + NewAPIErrorOptions 函数式选项模式组合配置；实现 Unwrap 以兼容 errors.Is/As，并提供 ToOpenAIError/ToClaudeError 在协议间转换。
- 文件来源抽象：file_source.go 定义 FileSource 接口及 baseFileSource 嵌入基类，URLSource/Base64Source 两种实现统一封装 URL 与 base64 两种来源，并通过 CachedFileData 支持内存/磁盘双模式缓存，带 OnClose 回调用于统计扣减。
- 计费与价格：price_data.go 的 PriceData 聚合模型单价、完成率、缓存倍率、图像/音频倍率及 GroupRatioInfo，配合 shopspring/decimal 做精确计费计算。
- 请求元数据：request_meta.go 定义 FileType/TokenType 枚举、TokenCountMeta/FileMeta/RequestMeta 描述一次请求的 token 计数与文件元信息。
- 通用容器：rw_map.go 提供泛型 RWMap[K,V]（基于 sync.RWMutex 的读写锁 map，实现 json.Marshaler/Unmarshaler）；set.go 提供泛型 Set[T]；channel_error.go 提供 ChannelError 通道错误结构。
- 依赖方向：本模块仅依赖 github.com/QuantumNous/new-api/common（用于 JSON 编解码与敏感信息脱敏）和标准库，不反向依赖任何业务子模块。
