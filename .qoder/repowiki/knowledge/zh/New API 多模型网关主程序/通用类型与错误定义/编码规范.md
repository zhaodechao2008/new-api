- 错误构造统一采用 NewXxx(...) 构造函数配合 ...NewAPIErrorOptions 函数式选项模式，便于叠加 skipRetry、StatusCode、隐藏消息等可选行为。
- 对外暴露的共享结构体使用 json tag 标注字段，对敏感字段通过 common.MaskSensitiveInfo 进行脱敏后再输出。
- 并发安全的集合类型（RWMap、Set）通过 struct 内嵌 sync.RWMutex/sync.Mutex 并在每个方法中显式加解锁，保证 goroutine 安全。
- 可序列化的类型均实现 json.Marshaler/Unmarshaler 接口，内部委托 common.Marshal/Unmarshal 以保持编码一致性。
- 文件来源通过 FileSource 接口抽象，具体实现（URLSource/Base64Source）嵌入 baseFileSource 复用缓存、注册状态与互斥锁。
