- 所有对外暴露的消息文本都通过 `keys.go` 中定义的 `MsgXxx` 常量引用，禁止在业务代码中直接写死字符串。
- YAML 翻译键采用 `领域.子域.具体项` 的分层命名（如 `auth.access_token_invalid`、`token.quota_negative`），与对应常量分组一一对应。
- 语言代码统一通过 `normalizeLang` 归一化为 `zh-CN` / `zh-TW` / `en` 三种之一，其他变体（如 `zh-tw-*`、`zh-*`）被映射到最近支持的代码。
- 对共享状态（bundle、localizers）的访问通过 `sync.Once` 初始化 + `sync.RWMutex` 读写锁保护，读路径优先走无锁快速路径。
- 跨包依赖通过函数回调注入（如 `common.TranslateMessage`、`userLangLoaderFunc`）而非直接 import，避免循环导入。
