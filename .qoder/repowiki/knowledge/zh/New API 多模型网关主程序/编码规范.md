- 所有外部依赖通过包级 InitXxx() 函数显式初始化，由 main 按依赖顺序调用而非隐式 init
- 后台任务以 go 协程形式启动，统一通过 service.StartSystemTaskRunner 或独立 goroutine 管理生命周期
- 错误处理使用 common.FatalLog/SysError/SysLog 分级日志，关键初始化失败直接 Fatal 退出
- 配置读取优先从环境变量，其次 .env 文件，最后默认值，通过 common.GetEnvOrDefault 统一获取
- HTTP 层严格分层：router 装配路由、middleware 处理横切关注点、controller 实现业务逻辑、service 聚合领域能力
