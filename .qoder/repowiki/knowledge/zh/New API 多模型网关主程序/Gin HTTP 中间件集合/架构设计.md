本模块以 Go 包 `middleware` 组织，每个文件对应一个独立的 `gin.HandlerFunc`（或返回该函数的工厂），通过 `server.Use(...)` 在 gin.Engine 上组合装配。
- 认证与授权：`auth.go` 实现 Dashboard 会话/PAT 令牌认证、`TokenAuth`/`TokenAuthReadOnly`/`TokenOrUserAuth`、角色权限 `RequirePermission`，并通过 `GetAuthIdentity`/`GetSessionAuthIdentity` 暴露上下文身份；`auth_origin.go` 处理来源校验。
- 路由分发：`distributor.go` 的 `Distribute()` 根据路径前缀（/v1、/v1beta、/mj、/suno、/pg 等）解析模型名并选择下游 Channel，设置 `ContextKey*` 系列上下文键供后续链路使用。
- 限流：`rate-limit.go` 基于 Redis Lua 脚本实现固定窗口算法，按 IP 或用户 ID 维度限流，未启用 Redis 时回退到内存限流器 `common.InMemoryRateLimiter`。
- 审计：`audit.go` 通过包装 `ResponseWriter` 捕获响应体，在 Admin/Root 写操作后自动记录操作审计日志，支持 i18n action 映射。
- 安全验证：`secure_verification.go` 基于 `X-Security-Proof` 头对敏感操作进行二次验证（2FA/passkey）。
- 通用中间件：`logger.go`（自定义格式化日志）、`recover.go`（panic 恢复）、`cors.go`（CORS + 版本头）、`cache.go`/`disable-cache.go`（缓存控制）、`gzip.go`（压缩）、`request-id.go`（请求追踪）、`body_cleanup.go`、`header_nav.go`、`i18n.go`、`stats.go`、`performance.go`（系统负载检查）。
- 适配器：`jimeng_adapter.go`、`kling_adapter.go` 针对特定平台的适配逻辑。
- 工具：`utils.go` 提供统一的 OpenAI/Midjourney 错误响应封装 `abortWithOpenAiMessage`/`abortWithMidjourneyMessage`。
依赖方向单向向外：仅依赖 `common`、`model`、`service`、`types`、`constant`、`i18n` 等上层包，不反向依赖业务 handler。
