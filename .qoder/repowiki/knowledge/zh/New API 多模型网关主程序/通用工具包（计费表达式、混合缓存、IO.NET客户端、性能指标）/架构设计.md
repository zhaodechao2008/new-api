pkg 目录由四个相互独立的 Go 子包组成，彼此无直接依赖，仅通过各自对外暴露的函数/类型被上层调用：
- billingexpr：基于 github.com/expr-lang/expr 将字符串表达式编译为 vm.Program，使用 SHA-256 哈希 keyed 的进程内 LRU 缓存（最大 256 条），并通过 ParseExprVersion 支持 v1: 版本前缀；types.go 定义 RequestInput/TokenParams/BillingSnapshot/TieredResult 等数据结构，compile/run/settle/round 分别承担编译、求值、分层结算与四舍五入职责。
- cachex：泛型 HybridCache[V] 封装 Redis（github.com/go-redis/redis/v8）与内存 hot.HotCache（github.com/samber/hot）的双后端策略，通过 ValueCodec[V] 接口实现编解码，Namespace 负责键名前缀隔离，Get/SetWithTTL/Keys/Purge/DeleteByPrefix/DeleteMany 等方法在运行时根据 redisEnabled() 选择后端。
- ionet：HTTP 客户端封装，Client 结构体持有 BaseURL/APIKey/HTTPClient 接口，DefaultHTTPClient 基于 net/http 实现；types.go 集中定义 Deployment/Container/Hardware/Location 等 JSON 请求响应结构，client.go 提供 NewClient/NewEnterpriseClient 工厂及 makeRequest 统一错误处理（APIError）。
- perf_metrics：按 bucketKey{model,group,bucketTs} 对 Sample 进行原子计数（atomicBucket + sync.Map hotBuckets），后台 goroutine flushLoop 定期持久化到 Redis（common.RDB）与数据库（model.GetPerfMetrics），Query/QuerySummaryAll 合并热桶与持久化数据生成 GroupResult/ModelSummary 结果集。
依赖方向单向向外：各子包只依赖 common/model/setting/perf_metrics_setting 等共享包，子包之间互不引用。
