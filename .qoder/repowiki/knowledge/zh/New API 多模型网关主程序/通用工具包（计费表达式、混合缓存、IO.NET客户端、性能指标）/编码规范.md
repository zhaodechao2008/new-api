- 对外 API 通过构造函数或工厂方法返回指针类型（如 NewHybridCache、NewClient、NewEnterpriseClient），配置项以 struct 传入而非分散参数。
- 可序列化数据结构统一使用 json tag 标注字段名，可选字段使用 omitempty 标记。
- 缓存键采用命名空间前缀 + FullKey 拼接方式，确保多租户/多环境隔离（cachex.Namespace、ionet.BaseURL）。
- 错误类型实现 error 接口并以结构化字段（Code/Message/Details）表达，便于上层统一处理。
- 并发安全的数据结构使用 sync.Map 或 atomic.Int64 组合，避免全局互斥锁成为热点。
