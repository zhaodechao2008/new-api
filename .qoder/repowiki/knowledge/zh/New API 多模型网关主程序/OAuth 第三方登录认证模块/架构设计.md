模块以 `provider.go` 中定义的 `Provider` 接口为核心抽象，所有具体提供商（GitHub、Discord、Linux DO、OIDC）均实现该接口，提供统一的 `ExchangeToken`、`GetUserInfo`、`IsUserIDTaken`、`FillUserByProviderID`、`SetProviderUserID`、`GetProviderPrefix` 等方法。

- `types.go` 定义共享数据结构：`OAuthToken`、`OAuthUser`、`OAuthError`、`AccessDeniedError`，作为各 Provider 之间的统一数据契约。
- `registry.go` 维护全局 `providers` 映射与 `customProviderSlugs` 集合，通过 `Register`/`RegisterCustom`/`Unregister` 等函数在 `sync.RWMutex` 保护下管理 Provider 生命周期，并支持从数据库加载/重载自定义 Provider。
- `generic.go` 实现 `GenericOAuthProvider`，基于 `model.CustomOAuthProvider` 配置通过 HTTP 调用任意 OAuth 服务，使用 `gjson` 按 JSONPath 提取用户字段，并内置基于 JSON 的访问策略引擎（支持 and/or 逻辑、12 种比较操作符、嵌套 group），用于细粒度授权控制。
- 各具体 Provider 文件（`github.go`、`discord.go`、`linuxdo.go`、`oidc.go`）在 `init()` 中通过 `Register` 自注册，各自处理特定厂商的 token 交换与用户信息获取逻辑。
- 依赖方向：Provider 实现 → registry → model/i18n/logger/common/system_setting，反向不依赖具体实现。
