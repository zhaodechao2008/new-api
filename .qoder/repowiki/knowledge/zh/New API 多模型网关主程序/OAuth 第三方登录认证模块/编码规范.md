- 每个 Provider 在文件顶部通过 `func init() { Register("slug", &Provider{}) }` 完成自注册，slug 作为唯一标识符。
- 错误统一通过 `NewOAuthError` / `NewOAuthErrorWithRaw` 构造 `*OAuthError`，携带 i18n 消息键与参数，连接失败时附加 `RawError` 用于日志。
- HTTP 请求统一使用带超时（5s 或 20s）的 `http.Client`，并在请求前记录 `[OAuth-<Name>]` 格式的调试日志，响应后记录状态码与关键字段。
- 用户信息获取失败时返回 `MsgOAuthUserInfoEmpty` 错误，token 交换失败返回 `MsgOAuthTokenFailed`，网络错误返回 `MsgOAuthConnectFailed`，形成统一的错误语义。
- Provider 通过 `GetProviderPrefix()` 返回形如 `"github_"` 的前缀，用于自动生成用户名；`SetProviderUserID` 将 provider user ID 写入 `model.User` 对应字段。
- 自定义 Provider 的访问控制通过 JSON 策略描述（`accessPolicy`），支持 `and`/`or` 逻辑、`eq/ne/gt/gte/lt/lte/in/not_in/contains/not_exists/exists` 等操作符，并通过 `evaluateAccessPolicy` 递归求值。
