### 素材库
- 定义：New API 系统中的多媒体资产管理功能模块，支持图片、视频、音频三类资源的分组管理、上传、导入和预览。包含素材组（AssetGroup）和素材项（Asset）两个核心概念，提供本地文件拖拽上传和公共URL导入两种方式。
- 别名：Assets Management、asset management

### 素材组
- 定义：素材库中的资源分类容器，每个用户可创建多个素材组进行资源组织。支持按 group_type（如 AIGC）和 project_name 进行分类，包含名称、描述、统计信息（素材总数、处理中数量、失败数量）。
- 别名：Asset Group、asset-group

### 素材类型
- 定义：素材的资源格式分类，系统支持三种类型：Image（图片）、Video（视频）、Audio（音频）。通过文件扩展名自动识别，支持的格式包括 .jpg/.jpeg/.png/.webp（图片）、.mp4/.mov（视频）、.mp3/.wav（音频）。
- 别名：Asset Type、asset_type

### 素材状态
- 定义：素材的生命周期状态，包含 Active（正常可用）、Processing（处理中）、Failed（处理失败）三种状态。用于标识素材的当前可用性和处理进度。
- 别名：Asset Status、status

### Provider Group ID
- 定义：素材组的唯一标识符，格式为 'group-' + 时间戳 + 随机字符串。与 user_id 组合形成唯一索引，确保跨用户的数据隔离。
- 别名：provider_group_id、ProviderGroupID

### Provider Asset ID
- 定义：素材的唯一标识符，格式为 'asset-' + 时间戳 + 随机字符串。与 user_id 组合形成唯一索引，用于标识具体的素材资源。
- 别名：provider_asset_id、ProviderAssetID

### AIGC
- 定义：素材组的默认类型标识，代表 AI Generated Content（人工智能生成内容）。当创建素材组时未指定 group_type，系统默认使用此值。
- 别名：AI Generated Content

### Local File Upload
- 定义：素材上传方式之一，支持通过拖拽或选择本地文件进行上传。受文件大小限制（默认200MB）和扩展名白名单控制，上传后自动生成预览和元数据。
- 别名：本地文件上传、file upload

### Public URL Import
- 定义：素材导入方式之一，通过输入公开可访问的URL链接来添加素材。系统会验证URL有效性并提取文件名作为素材名称，适用于远程资源的快速集成。
- 别名：Public URL、URL导入

### 双面板工作区
- 定义：素材库页面的核心布局模式，左侧面板显示素材组列表（可折叠），右侧面板显示选中组的详细信息和操作界面。支持响应式设计和移动端适配。
- 别名：Dual Panel Layout、双面板布局
